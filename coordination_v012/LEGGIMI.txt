COSA CAMBIA (solo Mac personale + catalogo gateway; VPS agent e Mac a noleggio no)
- delete_path: elimina file o cartella (max 500 voci, 64 MiB, niente link) con
  rollback durevole che ricrea cartelle, contenuti e permessi.
- copy_file: copia file o cartella (no sovrascrittura, max 500 voci, 64 MiB),
  rollback rimuove la copia.
- read_binary: lettura a blocchi base64 (192 KiB) con sha256 del file intero.
- upload_file: begin/chunk/commit/abort; blocchi in area privata dell'agent,
  scrittura unica solo se dimensione e sha256 coincidono; rollback durevole.
  Pratico per file piccoli (ogni byte passa dalla chat); file grandi via GitHub.
- enable_full_shell network='github': proxy CONNECT dentro l'agent, credenziale
  casuale per lease (in env, mai in argv), solo porta 443 verso github.com,
  api.github.com, codeload.github.com, objects/raw.githubusercontent.com,
  solo indirizzi pubblici. Il seatbelt apre soltanto la porta loopback del
  proxy; senza lease la shell resta senza rete. Il proxy si spegne con la shell.
  Limite noto: dentro il lease si puo leggere/scrivere su GitHub con le
  credenziali presenti nella workspace (scelta accettata "solo GitHub").
  Push: serve un token GitHub a grana fine messo da Andrea nella workspace.
- Shell: git e strumenti dei Command Line Tools eseguibili nel seatbelt.
- Catalogo: 29 strumenti (25 + 4).
